# Statistical Analysis of Similarity in Human- and AI-Generated Music

A data science research pipeline designed to evaluate and statistically test structural and harmonic similarities between human-composed and AI-generated music tracks.

---

## Setup & Requirements

> [!IMPORTANT]
> **Python Version Requirement**: This project **specifically requires Python 3.11** (not whatever Python version is set as your system default). Using a different Python version (such as Python 3.12, 3.13, or 3.14+) will cause `librosa` and `numba` dependencies to fail during installation due to missing pre-built wheels and LLVM compiler constraints.

### 1. Create and Activate Virtual Environment

**On Windows:**
```powershell
py -3.11 -m venv venv
.\venv\Scripts\activate
```

**On macOS / Linux:**
```bash
python3.11 -m venv venv
source venv/bin/activate
```

### 2. Install Dependencies

With the virtual environment activated, install the pinned project dependencies:

```bash
pip install --upgrade pip
pip install -r requirements.txt
```

## Project Overview

This project provides an empirical, statistical framework to assess harmonic and structural similarity between music corpora using:
- **Chroma CQT Feature Extraction**: Robust 12-dimensional pitch-class profile matrices extracted via `librosa`.
- **Key-Invariant Dynamic Time Warping (DTW)**: Circular pitch shifting across all 12 semitones to account for musical key transpositions, with distance normalized to $[0, 1]$.
- **Null Distribution Hypothesis Testing**: Permutation and reference-pool testing to calculate empirical p-values for observed similarity scores.

## Directory Structure

```text
music_similarity/
├── data/
│   ├── human_songs/        # Curated collection of human-composed audio files
│   ├── ai_generated/       # Music tracks generated by AI models
│   └── reference_pool/     # Unrelated reference audio files for empirical null distribution
├── features/               # Cached feature arrays (.npy format)
├── notebooks/              # Jupyter exploratory notebooks
├── results/                # Evaluation reports, plots, and test statistics
├── src/                    # Core pipeline package
│   ├── __init__.py
│   ├── extract.py          # Audio loading, Chroma CQT extraction, feature caching
│   ├── similarity.py       # Key-invariant DTW alignment and similarity scoring
│   ├── stats_test.py       # Empirical null distribution hypothesis testing
│   └── utils.py            # Audio path discovery and directory management
├── tests/                  # Automated unit test suite
│   └── test_similarity.py
├── .gitignore              # Git ignore rules for virtualenvs, caches, raw audio, and features
├── requirements.txt        # Pinned Python dependency manifest
└── README.md
```
